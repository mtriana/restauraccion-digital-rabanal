# Teaching sequence: *RestaurAcción Digital*

The educational design that turns the technology into learning. Materials are in Spanish, the language of the participants. This page summarizes them in English.

## Learning design

The sequence follows **Kolb's experiential learning cycle**, supported by **connectivism** (Siemens) and **situated learning**. Each phase of the cycle is paired with a specific technology:

| Phase (Kolb) | Activity | Technology | Time |
|---|---|---|---|
| 1. Concrete experience | "Taking the páramo's pulse": set up the station and read live climate data | Weather station + app | 30 min |
| 2. Reflective observation | "How are the páramo's vital signs?": interpret the traffic-light indicators | App indicators | 30 min |
| 3. Abstract conceptualization | "Why care for the páramo?": water regulation, Colombian páramo law, native species | App educational content | 40 min |
| 4. Active experimentation | Answer the plot questionnaire, receive the AI plan, plant a native tree | App questionnaire + GPT-4 + WhatsApp | 50 min |
| 5. Evaluation and feedback | Short automated quiz with immediate feedback, plus the final survey | WhatsApp chatbot | 20 min |
| | Breaks and adjustments | | 10 min |
| **Total** | | | **about 3 h** |

## Evaluation

- **Instrument:** Likert survey (file E).
- **Participants:** n = 5 inhabitants of the páramo, over 3 field visits.
- **Results:** [`../data/pilot_results_summary.csv`](../data/pilot_results_summary.csv).
- **Range:** between 84% and 100% favorable responses per item.
- **Most valued item:** the weather-station data (100%).
- **Main improvement requested:** more audiovisual content, and native-species information in the community's own vocabulary.
